### 重要经验
- **curl 报 5000 的假象**：`errors.py` 的 `_val` 把 `RequestValidationError.errors()`（含 bytes 的 input 字段）直接 `model_dump()` 序列化 → 触发 5000。当 curl 未显式 `Content-Type: application/json` 时请求被当 form 解析触发校验错误，进而暴露此既有 bug。**真联调统一用 Python urllib 传 JSON 最稳**（dev-token 用 urllib 正常，用 curl `--data-binary @file` 无 Content-Type 时 5000）。该 errors.py 序列化 bug 属既有技术债，本次未修（超出 S1/S2 范围），后续可单独处理。
- `--reload` 对 schemas 等文件有时不生效，改 schema 后务必手动重启 uvicorn 再验证。
